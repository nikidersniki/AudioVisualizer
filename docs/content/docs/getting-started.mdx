## First five minutes

1. Open `index.html` in a modern browser (Chrome / Edge / Firefox).
2. The **preset picker** appears — pick one of the bundled presets (Blobs, Colors, Pulsar, Rave, Wave) to get a working scene immediately, or close the picker to begin from a blank scene. The picker reappears every time you start a new project via **File → New Project**.
3. **File → Add Resources** and pick an audio file (or drag-drop one onto the window).
4. Click the **▶** button in the bottom bar to start playback.
5. In the **Layers** panel, click **+** on the base layer (skip if you loaded a preset).
6. Pick **Model**. A default mesh appears in the viewport.
7. Open its **Properties** — try toggling **Material Type** to `wireframe`, or change **Color**.

## Make it react

8. Find any numeric property (e.g. `Scale X` or `Spin Speed`).
9. Click the binding icon next to it and switch from `constant` to `audio`.
10. Pick a source: try `beat`, `bass`, or `rms`.
11. Set `min` and `max` to a useful range.

That's the loop: **add object → bind a property to a source → tweak min/max**.
