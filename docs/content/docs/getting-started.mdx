title: Getting Started

## First five minutes

1. Open `index.html` in a modern browser (Chrome / Edge / Firefox).
2. **File → Add Resources** and pick an audio file (or drag-drop one onto the window).
3. Click the **▶** button in the bottom bar to start playback.
4. In the **Layers** panel, click **+** on the base layer.
5. Pick **Model**. A default mesh appears in the viewport.
6. Open its **Properties** — try toggling **Material Type** to `wireframe`, or change **Color**.

## Make it react

7. Find any numeric property (e.g. `Scale X` or `Spin Speed`).
8. Click the binding icon next to it and switch from `constant` to `audio`.
9. Pick a source: try `beat`, `bass`, or `rms`.
10. Set `min` and `max` to a useful range.

That's the loop: **add object → bind a property to a source → tweak min/max**.
