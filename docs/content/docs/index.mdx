Revisualize 3D is a browser-based audio visualizer. Build scenes from models, waves, lights, and images; drive any numeric property from the live audio spectrum; stack shader and native post-processing effects per-layer or globally.

## Core concepts

- **Layers** — independent 3D scenes, each with its own render target and post-processing pipeline.
- **Objects** — models, waves, lights, and images live inside layers.
- **PropertyBinding** — every numeric value can be a constant or driven by an audio signal.
- **Post-processing** — stacks of shader/native passes, applied per-layer or globally.
- **Animation** — keyframe-style automation for properties that should change over time.
