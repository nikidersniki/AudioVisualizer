## File menu

| Item | What it does |
|---|---|
| New Project | Discards current scene. Prompts to save first. Creates an empty base layer. |
| Open Project | Loads a `.json` project from disk. |
| Load Preset… | Opens the preset picker. Shows live thumbnails of every bundled preset; click one to load. |
| Save Project | Downloads the scene as `{name}.json`. |
| Resources… | Opens the Resources manager — list imported audio, HDRI, background images, and video; delete individual entries; import new files. |

## Welcome screen

On a fresh launch — when no auto-saved project exists in IndexedDB — the app shows a welcome overlay with the preset picker. Pick one to start from a known-good scene, or hit **Start Empty** for a blank base layer. The same picker is available any time from **File → Load Preset…**.

Preset thumbnails are rendered live the first time you open the picker (the app briefly time-shares the renderer to capture each preset) and cached in `localStorage` keyed by the preset file's content hash, so subsequent opens are instant.

## Windows / Layout menus

- **Windows ▾** — toggle individual panels (Viewport, Layers, Properties, Animation, Audio Monitor).
- **Layout ▾** — reset the panel layout. Drag any tab to dock it as a new pane (powered by Golden Layout).

## Fullscreen viewport

The viewport panel has a `⛶` overlay button in the top-right corner. Click it to enter fullscreen — the gizmo overlay (TransformControls) and the gizmo-mode chip are hidden, and the letterbox / fixed-aspect frame expands to the full element so you get a clean render. Press `Esc` or click the same button to exit.

## Theme

In the **Settings** panel, open the collapsible **Theme** section. The picker is inline — six preset cards (**Terminal Noir** default, **Pure Dark**, **Light**, **Synthwave**, **Forest**, **Solar Flare**) plus a **Custom** card. Click a card to apply immediately.

Every CSS variable (border alphas, scrollbar colour, grain overlay, hover lifts, panel-glass tint) is derived from the seed's `bg / panel / accent / text` colours, so adding a new theme is just four hex values.

Below the cards: **Dark icons** checkbox (auto-derives from background luminance by default; manual override remembered per theme) and a **Customize** section with live colour pickers feeding the Custom card.

Theme choice persists in `localStorage` (`theme-name` + per-theme `theme-icon:{name}`) and applies before first paint on reload.

## Audio Volume

The volume slider in the Settings / Controls panel is a **global preference** stored in `localStorage` (`audio-volume-pref`). It is not part of a project file — loading a different project does not change your output level.

## Gizmo

When a 3D object is selected, the transform gizmo appears in the viewport. Switch modes from the top-center pill or with the keyboard.

| Mode | Key |
|---|---|
| Move | `T` |
| Rotate | `R` |
| Scale | `S` |

Dragging the gizmo writes back into the object's `posX/Y/Z`, `rotX/Y/Z`, or `scaleX/Y/Z` bindings — but only if those bindings are in `constant` mode. Audio-driven bindings ignore drag input (otherwise the live multiplier would fight the gizmo).
