---
title: Objects
description: The four object types you can place in a layer.
---

Every layer contains zero or more objects. Four types exist:

| Type | Use it for |
|---|---|
| [Model](/docs/objects/model) | 3D mesh from the catalogue. Reacts via material, scale, spin, displacement. |
| [Wave](/docs/objects/wave) | Frequency-spectrum visualisation in 6 styles. |
| [Image / Video](/docs/objects/image) | 2D plane with image or video texture. |
| [Point Light](/docs/objects/light) | Single point light source. Affects `standard` materials. |

All objects share these baseline controls: name, visibility, position, rotation, scale, global scale, opacity.
