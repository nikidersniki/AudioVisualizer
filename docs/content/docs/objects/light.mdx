---
title: Point Light
description: Single point light source.
---

Three.js `PointLight`. Properties:

| Property | Notes |
|---|---|
| Color | Hex color |
| Intensity | Binding |
| Distance | Binding — falloff radius |
| Position | Bindings on each axis |

Only affects objects using the `standard` material — `normal` and `wireframe` materials are unlit.
